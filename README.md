# Insonia Clone

## 📌 Sobre o Projecto

Projecto desenvolvido como exercício de programação durante o meu estágio curricular. O desafio consistiu em recriar uma página web existente, utilizando a página original como referência visual.

O exercício teve como foco reproduzir a estrutura, a disposição dos elementos e os estilos da interface, colocando em prática conhecimentos de desenvolvimento front-end.

> Este projecto tem finalidade educativa e de portefólio, sem vínculo oficial com os responsáveis pela página original.

---

## 🎯 Objectivo

Desenvolver a capacidade de analisar uma interface existente e reproduzi-la em código, prestando atenção à organização dos conteúdos, às cores, à tipografia e aos espaçamentos.

---

## 📚 Aprendizagens

Este exercício permitiu praticar:

- Análise de uma página web a partir de uma referência visual.
- Estruturação dos conteúdos de uma interface.
- Reprodução de estilos e composição visual.
- Ajuste de alinhamentos, dimensões e espaçamentos.
- Comparação entre a implementação e a página de referência.
- Organização do código durante o desenvolvimento.

## 📥 Como Instalar

1. Clona o repositório:

   ```bash
   git clone https://github.com/denildinis/insonia-clone.git
   ```

2. Acede à pasta do projecto:

   ```bash
   cd insonia-clone
   ```

3. Abre a pasta no teu editor de código.

Como alternativa, selecciona **Code → Download ZIP** na página do repositório e extrai os ficheiros para o teu computador.
